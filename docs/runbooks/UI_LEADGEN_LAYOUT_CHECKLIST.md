# UI Leadgen Layout Checklist

## Manual visual checks

1. Open `/app/finances` on desktop.
2. Scroll inside main content until footer is visible.
3. Confirm sidebar remains fixed on the left and does not move with main scroll.
4. Confirm there is only one active vertical scroll area (main content).
5. Switch to mobile width.
6. Open sidebar from `Menu` button and close it with backdrop and close button.
7. In light theme, verify language switcher text/options are readable.
8. In dark theme, verify language switcher text/options are readable.
